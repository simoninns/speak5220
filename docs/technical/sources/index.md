# Source documents

This section holds transcriptions of three original Texas Instruments documents that the project works from. They are third-party texts, kept as close to the originals as markdown allows: the wording, section numbering, capitalisation, tables and figures are TI's. They are split into pages for reading, and image paths point to the scanned figures stored with each document. Where the originals are incomplete or wrong, the project's own measured description of the chip, the [TMS5220 reference datasheet](../datasheet/index.md), gives the correct behaviour and cites these documents.

## [TMS 5220 Voice Synthesis Processor Data Manual](tms5220-data-manual/index.md)

TI's preliminary data manual for the TMS 5220 (June 1981, DM-02). It covers the CPU interface, the interface to the TMS 6100 Voice Synthesis Memory, the commands, the speech synthesis model and its parameter coding, the electrical and mechanical data, the system clock and timing appendices, and the coding table. The reference datasheet follows its section order.

## [TMS 6100 Voice Synthesis Memory Data Manual](tms6100-data-manual/index.md)

TI's tentative data for the TMS 6100 (June 1980), the 128K-bit serial ROM that holds speech data for the TMS 5220. It covers addressing, the internal and external chip selects, timing and the package.

## [US Patent 4,335,277](patent-us4335277/index.md)

*Control Interface System for Use with a Memory Device Executing Variable Length Instructions* (Puri, Texas Instruments, 1982). It describes a speech synthesizer and its CPU interface in detail, including block and logic diagrams, the parameter and chirp ROMs, and its tables.
