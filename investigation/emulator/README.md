# TMS5220 reference emulator

This folder holds a slot-accurate C99 emulator of the TMS5220, with a minimal TMS6100 VSM model and the `tms5220emu` command-line program, written from the reference datasheet alone.

Documentation: [docs/technical/emulator/](../../docs/technical/emulator/index.md), published at <https://simoninns.github.io/speak5220/technical/emulator/>.
