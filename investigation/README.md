# Investigation

Everything made to measure and document the TMS5220: the capture board (`kicad/`), its firmware (`firmware/`), the host tools (`tools/`), the captures (`captures/`), the speech PROM manifests (`proms/`), and the reference emulator (`emulator/`) written from the reference datasheet.

- Documentation: [docs/technical/](../docs/technical/index.md), published at <https://simoninns.github.io/speak5220/technical/>
- Building: [BUILD.md](../BUILD.md)

`local/` (git-ignored) holds third-party code and large working files that are not redistributed.
