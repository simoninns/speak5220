# Speech PROM manifests

This folder holds one manifest per original speech PROM (`<name>.json`: image hashes, provenance, target chip and word table); `python tools/promimport.py` rebuilds the images into `proms/images/` and writes the inventory page.

Documentation: [docs/technical/capture/prom-corpus.md](../../docs/technical/capture/prom-corpus.md) (published at <https://simoninns.github.io/speak5220/technical/capture/prom-corpus/>), with the generated inventory in [prom-inventory.md](../../docs/technical/capture/prom-inventory.md).
