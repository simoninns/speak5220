# Assets

Artwork for Speak5220.

| File | Contents |
|---|---|
| `logo/speak5220-icon.svg` | The application icon: one bar per LPC frame, sized by energy, in phosphor green (`#5cff9d`) on a rounded navy square (`#23314f` to `#151d33`) |
| `logo/speak5220-logo.svg` | The logo: the icon, with "Speak" in white and "5220" in the icon's green to its right, and a green line running from the tail of the "p" to the end of "5220", all on a black rounded panel so the logo works on light and dark backgrounds |

The wordmark is set in Adwaita Sans Bold (SIL Open Font License) and converted to paths, so the logo needs no font installed. The application's icon set (`.ico`, `.icns` and the PNG sizes for Flatpak) is generated from `speak5220-icon.svg` into `app/resources/`.
